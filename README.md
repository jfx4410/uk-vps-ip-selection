## 原生 IP、双 ISP、三网优化，三个词说的不是一件事

这几个词在商家页面上经常混着用，实际指三个不同层面。

**原生 IP** 指 IP 段由当地运营商分配、归属地显示为服务器所在地，而不是从别的地区广播过来。**双 ISP** 指同一个 IP 同时归属两家不同的英国宽带运营商，抗封能力理论上更强。两者的关系是单向的：双 ISP 必然是原生 IP，原生 IP 不一定是双 ISP。**三网优化**跟 IP 属性完全无关，说的是回程对中国电信、联通、移动做优化，常见方案是 CN2 GIA、联通 9929、移动 CMI/CMIN2，解决的是国内访问快不快。

WePC 这两档的命名也对应这个划分：14.90 那档卖的是 IP 出身，19.90 那档卖的是回国线路。

这里有个市面上很少提的反面意见。朝暮数据的官方帮助文档里直接写：某些网站提供的 IP 欺诈值检测并没有评分依据，IP 地址也没有“纯净”“干净”“新老”的说法，TikTok 这类公司有自己的 IP 地址库和检测手段。这个说法来自服务商自己的 FAQ，比推广文里“住宅属性是风控通行证”的叙事克制得多。落到实操上，你能做的是选一个归属地正确、带家宽属性的 IP，降低被判定成机房流量的概率；没有任何一家能保证某个 IP 一定不被风控。谁跟你保证，谁就是在卖话术。

## 真实成本怎么算，别被首月价带偏

比较英国VPS时最容易被坑的地方，是拿不同口径的价格放在一起比。

判断方法很简单：把页面上的价格分成三类记下来，标价（无码原价）、折后价（用了码的）、续费价（第二期开始付多少）。只比第一类，或者只比折后价，结论都会偏。

## 下单前要确认的几件事

**默认只有一个 IP。** WePC 每个套餐 1 个独立 IPv4，没有 IPv6。多账号运营需要多个 IP，得另外解决，别指望一台机器开几个实例就自动给你不同网段。

**流量是双向计费。** 2TB 双向意味着上传和下载加在一起算。直播推流、大文件上传这类场景消耗比你想的快，超了之后的处理方式（限速还是停机）页面上没写清楚，买之前问客服。

**拿到机器先验 IP。** 用 ipinfo 这类工具查一遍归属地和属性，第三方测评那台实例显示的是英国原生但商业属性，你自己买到的可能不同。查完不符合预期，趁还在月付周期内处理。
